# snake-tokscale — frontend

React 19 + Vite 8 + Tailwind 4 Snake game. Reads `grid.json` (generated by the
backend CLI) and renders a playable grid.

## Scripts

```sh
npm ci
npm run dev        # http://localhost:5173/snake-tokscale/
npm test           # Vitest unit tests (reducer / gridMath / foodSpawn)
npm run lint
npm run build      # emits dist/
```

## Configuration

All configuration is read from `../config.toml` at build time via `vite.config.js`
and injected as `__GAME_CONFIG__`, `__GRID_CONFIG__`, `__TOKSCALE_USERNAME__`.
No hardcoded values live in component code.

## Generating grid.json

```sh
cd ../backend
uv run python -m snake_tokscale --out ../frontend/public/grid.json
```

## Controls

- **Space** — start / retry
- **← ↑ → ↓** — move the snake
- Reach the target score (see `[game].win_score` in `config.toml`) to win
- Best score persisted in `localStorage` under the configured key
